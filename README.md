# Pizza Order Cost Calculator

## Project Overview

A simple Python program that calculates the total cost of a pizza order based on pizza size, number of toppings, and delivery distance.

## Features

- Accepts pizza size (small or large)
- Calculates the cost of additional toppings
- Calculates delivery fees based on distance
- Validates pizza size input
- Displays the final order total

## Technologies Used

- **Python 3** - Programming language
- **Visual Studio Code** - Code editor
- **Git** - Version control
- **GitHub** - Code hosting

## Getting Started

### 1. Clone the Repository

Open your terminal and run:

```bash
git clone https://github.com/a-gbatie/Pizza-Order-Cost.git
```

### 2. Navigate to the Project Directory

```bash
cd Pizza-Order-Cost
```

### 3. Run the Program

Make sure Python 3 is installed, then run:

```bash
python3 pizza_order_cost.py
```
